## Review and modeling handoff

Visually inspected all four outputs: full-body views and expressions are present, characters are not cropped, and the main costume and silhouette anchors are readable. Along's yellow wristband is on his anatomical right in the front and back views. Pak Mat's sarong and Mak Som's skirt read as continuous garments.

These are design concepts, not calibrated blueprints. Head-to-body ratios, pattern placement, fingers, sandal straps, perspective and view-to-view silhouette alignment need to be reconciled on whichever sheets the user selects. Generated proportions take precedence over unachieved aspirational ratios in the prompts only after user approval. Treat printed heights as proposed dimensions, not measured image evidence.

Once selected, use the blender-image-to-3d skill: preserve the source sheet in the asset reference folder, identify and crop each view, measure the approved proportions, document inferred geometry, build the calibrated master, and compare blockout renders before adding detail. The existing project uses Unity, but confirm the delivery requirements from the project at modeling time.
