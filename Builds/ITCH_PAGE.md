# Kampung Run: KL - itch.io upload guide

## Upload
1. On itch.io go to **Dashboard → Create new project**.
2. **Kind of project:** HTML.
3. **Uploads:** upload `KampungRunKL_web_itch.zip` and tick **"This file will be played in the browser"**.
4. **Embed options:**
   - Viewport dimensions: **1280 × 720**
   - Tick **Mobile friendly**, with orientation **Landscape**
   - Tick **Fullscreen button**
   - Leave **Automatically start on page load** off (players tap to start, which also lets the game play sound)
   - Leave **SharedArrayBuffer support** off (not needed)
5. **Pricing:** $0 or donate. **Visibility:** Public, then Save.
6. Copy the page link to share it.

The zip is compressed with gzip and decompression fallback, so it works on itch.io (or GitHub Pages, Netlify, any static host) with no server settings.

## Suggested page text

**Title:** Kampung Run: KL

**Short description:** Drive, punch and kick your way across a cartoon Kuala Lumpur, from Kampung Baru to KLCC.

**Description:**

A love letter to open-city driving games from the early 2000s, set in a bright cartoon Kuala Lumpur.

Play as Pak Mat, Mak Som, Along and Adik, a Kampung Baru family who discover that MegaMaju Berhad's "Cendol Ajaib" is turning KL into obedient zombies. Then ride with Aiman, a Chow Kit delivery rider, in a bonus chapter.

- 5 levels and 25 story missions, plus street races
- Drive kereta, a taxi, a food truck and a delivery kapcai
- Punch, kick and stomp. Jump on your neighbours' cars.
- Explore Kampung Baru, Chow Kit, Brickfields, KL Sentral, Muzium Negara, Taman Botani Perdana, Masjid Negara, Bukit Bintang and more
- Collect Kad Lat cards, smash MegaMaju's robot mynah birds, and keep the Meter Saman down

**Controls (keyboard / mouse)**
| | |
|---|---|
| Move | WASD / arrow keys |
| Look | Mouse (click the game to capture it) |
| Jump / double jump / handbrake | Space |
| Punch (3-hit combo) | Q / left click |
| Kick (in mid-air: stomp) | F / right click |
| Enter car / talk | E |
| Run | Shift |
| Horn / reset car | H / R |
| Pause | Esc |

A gamepad works too.

**Controls (phone / tablet, landscape)**
- Left thumb: move / steer
- Swipe the right side: turn the camera
- Buttons: LOMPAT (jump, or BREK in a car), TUMBUK, TENDANG, E, LARI, HON, BALIK, II (pause)
- Tap to advance dialogue and pick menu options

Progress saves in your browser.
